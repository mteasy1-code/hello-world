# ELAN 中文课堂转录辅助工具（Linux x86_64）

本工具包提供便携 CPython 3.11、Faster Whisper 1.2.1、多语言 small 模型和本地音视频转录脚本，使用 CPU int8 推理。PyAV 随依赖提供音频解码库，用户无需另外安装 Python 或 FFmpeg。适用范围以本次实际验证的 Ubuntu 22.04 / 24.04 x86_64 为准，其他系统需另测。

## 使用

下载 Actions 产物 `elan-asr-verified-linux-x86_64`，解开外层 ZIP 后执行：

```bash
sha256sum -c elan-asr-linux-x86_64.tar.gz.sha256
mkdir elan-asr
tar -xzf elan-asr-linux-x86_64.tar.gz -C elan-asr
cd elan-asr
python/bin/python3 manifest.py . --verify
./run.sh /绝对路径/课堂录音.wav --output /绝对路径/输出/课堂初稿
```

输出前缀不要带扩展名；已存在的 JSON、SRT 或 EAF 会触发停止，以保留已有成果。支持 PyAV 可以解码的本地音视频文件。运行脚本强制中文转录并禁用网络连接；模型、分词器均从包内读取。

输出包括 JSON（段落和词级时间戳）、SRT、EAF。EAF 使用 `ASR_待分人` 轨道；在 ELAN 中核对媒体链接、文字和时间边界后，再将经核验的发言分配到 T、S1、S2 等轨道。移动 EAF 时请同时保持媒体相对路径，或在 ELAN 中重新关联原始媒体。

## 在 ChatGPT 对话中调用

个人技能名为 `elan-classroom-asr`，显示名为“ELAN 中文课堂转录”。在支持个人技能与 Linux 执行环境的 ChatGPT Work 对话中选择该技能，再提供实际课堂音视频；技能负责获取已验收运行时、校验、安装并执行识别。当前对话可直接继续使用。其他客户端能否出现技能选择项，以该客户端实际提供的技能功能为准。

完整产物约 616 MB，超过 GitHub 连接器单次 512 MiB 的下载限制。供技能使用的 `elan-asr-runtime-part-00`、`01`、`02` 是三个独立产物，每卷最多 240 MiB。逐卷下载，校验 GitHub 返回的各 ZIP SHA256，再按包内分卷清单重组 tar.gz 并校验完整归档；不能只下载其中一卷。完整包继续保留，供用户直接下载。

对话调用示例：“使用 ELAN 中文课堂转录技能，处理附件录音，输出 EAF、SRT、JSON 和验证记录。”教师与学生身份及重叠发言按实际媒体复核；未核验的自动结果仍保留在初稿轨道。运行时不会把课堂音视频上传到 GitHub。

## 验证证据

`verification/` 包含依赖检查、导入版本、完整依赖锁定清单、模型仓库精确修订号、构建提交、短音频识别结果与验证报告。`MANIFEST.json` 记录包内文件 SHA256、大小、权限和符号链接；外层 SHA256 用于检查压缩文件。GitHub 工作流对重新下载的产物在两个全新 Ubuntu 环境中进行解包、迁移、空缓存推理和输出一致性检查。

短音频来自 FunASR 公共示例，精确 URL、Git blob 校验值和上游许可保存在包内。验收参考文本为“欢迎大家来体验达摩院推出的语音识别模型”。字符错误率仅用于这个短示例；自动检查的段落、词级时间戳、SRT 与 EAF 一致性只证明输出结构和边界有效。它们不等于真实课堂的逐字正确率或时间边界人工测量精度。

模型和运行依赖使用各自上游许可；Python 安装目录保留其许可，模型目录保留可用的模型说明。模型精确修订号随产物记录；后续构建可能解析到新的模型版本或间接依赖版本，重建前应参照已验收产物中的锁定清单。

## 课堂应用边界

本版本提供转录初稿，不包含经验证的说话人聚类、教师与学生身份映射、声源分离或重叠发言分类。现有 ECAPA 模型下载成功也不能直接证明这些功能可用。课堂中的齐读、错峰齐读、齐答、错峰齐答及重叠的不同内容，需要结合实际音视频逐段核对并写入对应 EAF 轨道。small 模型适合运行验收，复杂课堂可另行评估更大模型和定制分人流程。

## 代码与回滚

修复位于独立分支，现有工作流和历史版本保留。新工作流独立构建完整运行时；原有 wheel 下载工作流仍可单独使用，但 wheel 下载成功只代表依赖获取完成。默认分支合并由仓库所有者确认。回滚可关闭修复 PR，或在合并后撤销相关提交，无需删除历史文件。
